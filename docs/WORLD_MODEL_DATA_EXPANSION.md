# 世界模型数据补充与使用方案（2026-10-12）

## 当前结论

租赁成交历史的规模已经足够支撑价格基线研究，但数据覆盖、连续观测、真实行动与结果、模型输入接线仍不完整。不能用更多成交价格替代押金返还事件。

本仓库已有 6,103,069 条标准化来源出现次数、2011–2024 年度隐私聚合、人口/地区/考试院/地铁背景。当前 `worldmodel_data/model_v0.py` 只消费 `seoul-rental-price-files` 年度价格聚合；场景中的预算、临时住宿费、核验状态和核验耗时均为合成/建模参数，不是已经采集的真实用户旅程。

已新增 `compile-rtms-features`，把 API 包编译为“合同月 × 区 × 来源住宅类型 × 月租/全租”的可追溯价格特征，保留每个基线的 observed_at，不将旧合同年份当历史数据可见时间。特征不是训练完成的预测器，尚未改写 v0 的年度来源准入。人口、利率与 HUG 也不因文件放在一起就自动进入模型。

## 怎么在模型里使用

数据分为事实层、特征层、情景参数、真实结果四部分，不能简单拼成一张“大表”。

1. 事实层：原始版本、来源、合同日期、来源申报日期（缺失则空）、本机观察时间和稳定地区键。
2. 特征层：同范围、同口径分组的价格分位数、样本量、建筑/面积可用性、迟发现区间、分页完整性；每个特征携带输入哈希、观察时间、可用性限制和 missing mask。
3. 情景层：用户授权的现金预算、押金承受上限、月度预算、搬入期限、目的地与临住约束。没有观察证据的费用/时间只能标为 modeled 或 synthetic。
4. 结果层：实际核验结果、签约/退租/返还/纠纷经过，作为未来状态转移与结果校准证据；当前数据不提供这些标签。

宏观数据按时间口径接入：BOK 按生效日期作阶梯序列，HUG 按年度/产品保留，市场指数按官方地区及基期；不要把全国年度值当区级月度值或合同个体概率。模拟某个过去决策日时，只能使用当时可证明已知的版本；当前采到的历史表不自动满足历史 as-of 回放。

当前价格模型独立抽样押金和租金边际分位数，属于机制压力测试，不能声称还原实际押金/月租联合分布。实际训练数据应保留每条合同的押金与月租配对。新增特征编译器同时提供配对相关系数，作为描述性关联，不是因果关系或完整联合模型。

```powershell
python -m worldmodel_data compile-rtms-features `
  --input-package data/work/share-packages/nestlinker-worldmodel-collected-20261012 `
```

产物 `market-features.json` 包含 27,199 个价格单元，输入 6,103,069 条，代表 6,095,467 条；1,292 个不足 10 条的组及其 7,602 条来源记录被抑制，行数守恒。特征输出会随观察版本更新，不覆盖旧输出。P25/中位数/P75 使用线性插值；source multiplicity 保留，不声称唯一合同量。面积严格保留专有口径，不用 totalFloorAr 顶替。

## 押金返还事件最少要收什么

至少保存匿名 lease_id、事件类型、实际发生时间、系统记录时间、金额及单位、事件状态、核验角色、证据引用/哈希、同意与撤回状态；私有主体信息另置受控存储，不进公开仓库。

事件顺序覆盖：核验 → 签约 → 入住/续约 → 解约/到期 → 退租/交接 → 应返金额/约定日期 → 实际返还（可多次部分返还）→ 争议/调解/诉讼 → 结案/保证赔付。未到期、仍在等待、失联或未取得结果须标为右删失/未知，不能填成“已返还”或“损失”。保证机构赔付与房东按时返还应分开记录。纠纷受理也不是已经确认损失。

这部分需要后端、知情同意和真实业务合作，公共 API 无法补造。当前工作继续限定价格基线、时效/质量模型与特征编译，不训练大模型或生成安全评分。
